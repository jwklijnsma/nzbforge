# nzbforge Documentation

Welcome to the documentation for nzbforge, a Newznab-compatible Usenet indexer with Python (FastAPI) backend and React frontend.

## Key Features

- Full Newznab API compatibility for Prowlarr/Sonarr/Radarr
- MySQL/MariaDB database support
- Secure API key management interface
- Automatic release classification with TV/movie metadata

## User Roles
- **Admin**: Full administrative access to all features, including user management and system configuration.
